# NeuroPsychAtlas

NeuroPsychAtlas is a neuropsychiatric disease burden genomics resource. Explore population allele-frequency associations with migraine, depressive-disorder and bipolar-disorder burden across 20 countries, 1990–2023.

Select a disease, outcome and available sex stratum. Query by rsID, variant identifier, gene or genomic interval. Export matching records as TSV or CSV and use Downloads for the selected disease's supporting data.

The query collection uses P < 10⁻⁵. Discovery leads use P < 5 × 10⁻⁹ followed by LD filtering. The catalog lists available groups for each disease. Coordinates use GRCh38; burden rates are per 100,000. βCAF is the country-level rate difference per 0.01 increase in REF frequency at SDI = 0.

Primary resources: [GBD](https://ghdx.healthdata.org/gbd-results-tool), [1000 Genomes](https://www.internationalgenome.org/), [MVP](https://www.ebi.ac.uk/gwas/studies/GCST90480017) and [PGC](https://pgc.unc.edu/for-researchers/download-results/). External GWAS source files are obtained from their original providers.
